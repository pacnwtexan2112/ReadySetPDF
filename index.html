The full prepress arsenal

ReadySetPDF does not just view files. It engineers them for press.

Imposition, VDP, fold proofs, preflight, marks, and batch tools in one Windows workspace — the jobs shops actually run, not a cloud PDF editor.

  • Overnight production

    Automated hot folders

    Watch folders on your local network apply saved templates, impositions, and prepress checks unattended. Drop files in before you leave — jobs are press-ready in the morning.

  • Mail merge on your hardware

    Variable data printing

    Link CSV or Excel columns to a PDF template with drag-and-drop field tags. Preview a merged record, skip blank rows, and run 10,000+ record streams without a browser or a cloud upload.

  • Sheet yield

    Step & repeat imposition

    Set rows, columns, and gutter spacing, then step a single record into a multi-up press sheet. Anchor a selection so pieces stay locked when the grid changes. Built for business cards, tags, and labels on 12×18 and 13×19 stock.

  • Reader to printer spreads

    Saddle-stitch booklet maker

    Paginate multipage files into 2-up printer spreads with spine creep per sheet from your paper thickness. Outward moves toward the spine; inward opens the gutter. A 3×3 white-space anchor pads from the chosen cell. Monkey, Grid, and Booklet tabs can honor the TrimBox instead of the MediaBox.

  • Proofs with die lines

    Fold type previews

    Preview letter, tri-fold, gate, Z-fold, and other common bindery folds on the live page. Export a customer proof with die lines so finishing sees the same folds you quoted.

  • Catch it before plate

    Prepress preflight reports

    Scan incoming PDFs for missing fonts, low-resolution images, RGB versus CMYK, and trim or bleed box errors — before they cost a reprint.

  • Owner-password jobs

    PDF unlock & decryption

    Strip owner passwords and print-lock restrictions from client files so you can preflight, impose, and send to the RIP without a detour.

  • Folders, not one-offs

    Batch processing

    Merge dozens of PDFs into one optimized run, or apply crop marks and scaling to hundreds of files in a single pass.

  • Bindery indicators

    Crop & bleed marks

    Apply crop marks in black or white on Monkey, Grid, and Booklet, with positive or negative overlap so marks cross into trim or sit off it. Cutter L, registration, and dots align to the four corners.

  • Break the monster file

    Page extraction & splitting

    Pull a page range, split a 10,000-page stream into press-sized chunks, or lift a single record out of a corrupted print file.

  • Duplex and chapters

    Blank page insertion

    Force right-hand chapter starts, pad to booklet page counts, or fix duplexing so backs don't print on the wrong leaf.

  • Force it to the stock

    Document resize & scale

    Map non-standard client PDFs to Letter, Tabloid, or a custom size while keeping aspect ratio, centering art, and updating the trim box.

  • Tesseract on the desktop

    Optical character recognition

    Extract text from flattened scans into CSV or TXT, or inject an invisible text layer for searchable archival PDFs — without sending files off-site.

Prepress software FAQ

Straight answers for shop owners comparing local automation to cloud PDF tools.

What is ReadySetPDF?

ReadySetPDF is Windows prepress automation software for small and mid-sized print shops. It handles hot folders, variable data printing (VDP), saddle-stitch booklet imposition, fold-type proofs with die lines, step-and-repeat, PDF preflight, crop marks, and batch processing — entirely on your own hardware.

Is ReadySetPDF free to download?

Yes. Version 3.53 is a free download for Windows. Source is public on GitHub. A Pro license is planned; the current build is provided as-is during beta.

Does ReadySetPDF work offline?

Yes. Files never upload to a browser or a cloud queue. That means no file-size caps, no wait on a shared server, and no PHI or customer lists leaving the shop — which matters for healthcare mail and other regulated work.

What is a prepress hot folder?

A hot folder is a watched directory. Drop a PDF in, and ReadySetPDF applies the template, imposition, and checks you saved for that folder. Shops use it to run overnight work so morning shifts start with press-ready files instead of a prepress backlog.

Can ReadySetPDF do variable data printing (VDP)?

Yes. Version 3.5 added a visual VDP editor: spreadsheet headers become <> tags, you place fields on a live template preview, and output page count is template pages times rows that actually contain data. Address blocks format City, ST ZIP on one line. The engine is built for 10,000+ record runs.

Can ReadySetPDF preview fold types?

Yes. Fold-type previews cover common bindery folds such as letter, tri-fold, gate, and Z-fold. You can export a proof with die lines so the customer and the finishing department are looking at the same fold layout.

Does the booklet maker compensate for spine creep?

Yes. Creep is paper thickness; each inner signature adds that amount. Outward moves content toward the spine; inward opens the gutter. A 3×3 white-space anchor pads margins from the chosen cell, same as Grid.

What preflight checks does ReadySetPDF run?

Preflight reports look for missing fonts, low-resolution images, RGB versus CMYK color space, and incorrect trim or bleed box definitions — the errors that show up on press, not on a laptop screen.

What is ReadySetOCR?

ReadySetOCR is a companion Windows utility for live hot-folder OCR. Use it when you need a dedicated multi-pipeline watch folder for scans. ReadySetPDF also includes Tesseract OCR for one-off extraction and searchable PDFs.

What are the system requirements?

Microsoft Windows. ReadySetPDF 3.53 installs with a setup executable. ReadySetOCR ships as a zip — run the exe in the unzipped folder. Neither tool requires a browser or an online account.

Does ReadySetPDF work with MediaBox, CropBox, and TrimBox?

Yes. On import you can keep the original boxes, set CropBox to TrimBox, or clip extra margins to TrimBox. Those choices apply to preview, export, and batch. Monkey, Grid, and Booklet can also honor the TrimBox for imposition.

What's new in ReadySetPDF 3.53?

Page geometry on import with MediaBox, CropBox, and TrimBox controls for preview, export, and batch. Booklet creep per sheet with outward or inward direction, plus a 3×3 white-space anchor. Crop-mark overlap and black or white marks on Monkey, Grid, and Booklet. Cutter extra marks sit on the corners. Preview tick rulers and Fit Width zoom. Grid 3×3 pad cells stay clickable. Earlier tools stay in: TrimBox options, fold-type proofs, dual crop marks, CropBox clipping, and the 3.5 visual VDP editor.
